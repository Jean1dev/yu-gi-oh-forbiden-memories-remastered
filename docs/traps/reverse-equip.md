# 689 — Reverse Trap

Quando o oponente joga um equipamento, a trap transforma o bônus daquele anexo em penalidade de
mesma magnitude. A polaridade fica no anexo, não na carta: `atk` e `def` base nunca são alterados.

Filtros de classe continuam valendo. Um equipamento incompatível pode consumir a trap, mas
contribui zero. Depois de todos os modificadores, ATK e DEF efetivos têm piso zero.
